# Human or Machine? - Detector of AI-Generated Text in Spanish

## Description
This project is developed for the Deep Learning course. It implements and compares an NLP detection system to distinguish between human-written and machine-generated text in Spanish using:
1. A baseline model (TF-IDF + Logistic Regression).
2. A pre-trained GPT-2 model using text perplexity.

## Project Structure
- `notebooks/`: Contains the technical report and training notebooks.
- `app/`: Source code for the user interface.
- `data/`: Sample datasets and data sources.
